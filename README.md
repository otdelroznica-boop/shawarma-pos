# Shawarma POS

Касса для точки быстрого питания: приём заказа, кухня, табло для гостей, товары и отчёты.
React + Vite + Tailwind на фронте, Express + Prisma + PostgreSQL на бэкенде.

## Демо

**https://otdelroznica-boop.github.io/shawarma-pos/** — работает прямо в браузере, ставить ничего не нужно.

- Администратор: `admin@demo.ru` / `demo123`, кассир: `kassa@demo.ru` / `demo123` (на экране входа — кнопки выбора).
- Есть история продаж за неделю, чтобы отчёты не были пустыми.
- Данные хранятся только в вашем браузере. Кнопка «Демо-режим» в меню возвращает всё в исходное состояние.
- Табло для гостей в демо: https://otdelroznica-boop.github.io/shawarma-pos/#board (в том же браузере, где выполнен вход).

Демо собирается командой `npm run build:demo` в `frontend` (API эмулируется в `src/demo/mockApi.ts`)
и публикуется автоматически при каждом push в `main`.

## Запуск

Двойной клик по `start-all.bat`. Скрипт обновит структуру базы, поднимет сервер (порт 4000)
и интерфейс (порт 5173), дождётся готовности и откроет браузер.

Вручную:

```bash
cd backend && npx prisma migrate deploy && npm run dev
cd frontend && npm run dev
```

Перед первым запуском скопируйте `backend/.env.example` в `backend/.env` и укажите пароль PostgreSQL.

Первичное наполнение пустой базы (администратор и меню): `cd backend && npm run seed`.

## Разделы

| Раздел | Что делает |
|---|---|
| Касса | Каталог по категориям, поиск (клавиша `/`), добавки к шаурме и соусы к снэкам, предложение напитка. Оплата наличными со сдачей или картой (`F9`). После оплаты — номер заказа и печать чека |
| Кухня | Три колонки: новые, готовятся, готовы. Таймер готовки (жёлтый после 5 мин, красный после 10), отметка каждой позиции, звук на новый заказ, стикер на пакет |
| Табло | `http://localhost:5173/#board` — открыть на втором мониторе. Номера «готовится» и «можно забирать». Нужен вход в кассу на этом же компьютере |
| Товары | Цена, себестоимость, наценка, остаток. Приход и списание. Удаление товара с продажами переносит его в архив, история сохраняется |
| Отчёты | Сегодня, вчера, 7 дней, месяц. Выручка, валовая прибыль, средний чек, среднее время готовки, нагрузка по часам, структура по категориям и оплатам, топ товаров, журнал. Выгрузка в CSV для Excel |
| Сотрудники | Только администратор: добавить кассира или администратора |

## Жизненный цикл заказа

Принят (номер за день: 001, 002…) → «Начать готовить» → все позиции отмечены или «Всё готово»
(номер появляется на табло) → «Выдать гостю» (заказ уходит из очереди).

## Права

- Кассир: касса, кухня, просмотр товаров и отчётов.
- Администратор: плюс изменение товаров и остатков, сотрудники.

## Проверки на сервере

- Сумма чека считается на сервере, а не берётся из запроса.
- Продажа сверх остатка отклоняется с понятным сообщением.
- Создание заказа и списание остатков — в одной транзакции.
- Наличными нельзя внести меньше суммы заказа.

## Ограничения

- Себестоимость в отчётах берётся из текущей карточки товара, а не на момент продажи.
- Чек печатается через печать браузера (ширина 80 мм), прямой печати на ККТ нет — это не фискальный чек.
- Добавки и соусы заданы в коде: `frontend/src/lib/catalog.ts`.
